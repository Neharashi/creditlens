# Financial Terms Glossary — CreditLens

| Term | Meaning |
|---|---|
| DTI (Debt-to-Income ratio) | Monthly debt payments ÷ monthly income — higher = riskier borrower |
| Loan Grade | Lending Club's own risk rating (A = safest, G = riskiest) |
| Charge-off | A loan the lender has given up collecting on — treated as a loss |
| Delinquency | Borrower is late on payments but hasn't defaulted yet |
| Revolving Utilization | % of available credit (e.g., credit card limit) currently used |
| Default | Borrower has failed to repay according to the loan terms |
