# CreditLens — Loan Default Risk & Portfolio Analytics Platform

## Problem Statement
Lenders need to assess the risk of a loan defaulting before approving it,
and understand which segments of their loan portfolio carry the most risk.
This project builds a model to predict loan default probability, segments
borrowers by risk tier, and presents portfolio-level risk analytics through
a dashboard.

## Dataset
Lending Club loan dataset (peer-to-peer lending), starting with a curated
~10,000-row, 55-column subset for learning, scaling up later if needed.

## Planned Build (staged)
- Phase A: EDA + a first simple default-prediction model (logistic regression)
- Phase B: Feature engineering + improved model (XGBoost) + risk segmentation
- Phase C: SQL storage + dashboard (Power BI/Tableau) + Excel executive report
- Phase D: NLP on loan purpose text + API (FastAPI) + Docker deployment

## Tech Stack
Python, pandas, scikit-learn, XGBoost, SQL, Power BI/Tableau, FastAPI, Docker
